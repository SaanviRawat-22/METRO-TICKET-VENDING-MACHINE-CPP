# 🚇 Metro Ticket Vending Machine

A beginner-friendly C++ console application that simulates a Delhi Metro Ticket Vending Machine. This project allows users to select stations, calculate fares, choose a payment method, verify payment using an OTP (for UPI), and generate a ticket.

---

## ✨ Features

- Welcome screen
- Station selection using station codes
- Automatic fare calculation
- Supports multiple passengers
- Payment options:
  - UPI (with OTP verification)
  - Cash
- Random OTP generation
- Ticket generation after successful payment

---

## 🛠️ Technologies Used

- C++
- Console Application
- Visual Studio Code

---

## 📋 How to Run

1. Download or clone this repository.
2. Compile the `.cpp` file using any C++ compiler.
3. Run the program.
4. Follow the on-screen instructions.

---

## 🔄 Project Flow

1. Welcome Screen
2. User Confirmation
3. Select Origin Station
4. Select Destination Station
5. Fare Calculation
6. Select Number of Passengers
7. Choose Payment Mode
8. OTP Verification (UPI only)
9. Ticket Generation
